# Mubashir Ahmad — Portfolio Website

- `index.html` — the finished site (all images built in). Open it in any browser, or upload it to any host.
- `src-template.html` — the editable source. Images appear as `__PHOTO__` / `__IMG_name__` placeholders.
- `assets/` — your photo, client-store screenshots and stock photos (Pexels).
- `build.py` — run `python3 build.py` after editing the template to rebuild `index.html`.

To edit in Claude Code: open this folder in a terminal, run `claude`, and ask for changes
(for example "add a new project card for X using assets/x.jpg").
